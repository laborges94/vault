# Agent Guidelines

This repository is an open-source C#/.NET template. All AI agents, coding assistants, and automated tools working on this codebase must adhere to the following rules:

## Language
- **Strictly English**: All code, identifiers, comments, XML documentation (`///`), commit messages, PR descriptions, documentation, and file names must be written in **English**, regardless of the language used in user prompts or chat conversations.

## Project Standards
- Follow the conventions detailed in [.github/copilot-instructions.md](.github/copilot-instructions.md).
- Adhere to formatting and style rules configured in [.editorconfig](.editorconfig).
- Use [Conventional Commits](https://www.conventionalcommits.org/) for all commit messages (`type(scope): description`).

## Documentation & README Maintenance
- **README Synchronization**: For every change (including architectural decisions, new features, altered build/run steps, prerequisites, dependencies, or directory structure updates), verify whether the changes impact or misalign with [README.md](README.md). Always update and keep [README.md](README.md) accurate and aligned whenever applicable.
